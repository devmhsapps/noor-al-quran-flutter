# نور القرآن — Flutter

هذه نسخة Flutter/Dart مستقلة ومخصصة لـ Android لتجربة **وضع الجامع** فقط. تتصل واجهة Dart بوحدة Kotlin محلية بواسطة `MethodChannel`، وتتحقق من صلاحية عدم الإزعاج قبل بدء جلسة مؤقتة. تحفظ الخدمة الأمامية مرشح عدم الإزعاج السابق ثم تعيده عند الإلغاء أو انتهاء الوقت، وتصدر تنبيهًا عربيًا صوتيًا ومرئيًا عند انتهاء الجلسة.

## التشغيل محليًا

يتطلب المشروع Flutter SDK وAndroid SDK. بعد تثبيتهما شغّل:

```bash
flutter pub get
flutter test
flutter run
```

> لا يدعم المتصفح كود Android الأصلي. يجب اختبار صلاحية عدم الإزعاج والخدمة الأمامية والتنبيه الصوتي على هاتف Android حقيقي.

## APK ورابط تنزيل خارجي

يتضمن المشروع سير عمل GitHub Actions في `.github/workflows/build-apk.yml`. عند رفع وسم إصدار مثل `v1.0.0` إلى مستودع GitHub عام، يبني السير العمل ملفات APK ثم ينشرها في صفحة الإصدار. يصبح رابط تنزيل نسخة arm64 بالشكل التالي:

```text
https://github.com/OWNER/REPOSITORY/releases/download/v1.0.0/noor-al-quran-arm64-v8a.apk
```

يجب استبدال `OWNER` و`REPOSITORY` باسم المستودع الحقيقي. يحتاج الهاتف إلى السماح بالتثبيت من المصدر الذي يفتح الرابط عند تثبيت APK لأول مرة.

الإصدار التجريبي الحالي يُوقّع بمفتاح debug صالح للتثبيت خارج Google Play، ويجري التحقق من توقيعه في سير البناء قبل نشر الأصول. لا يصلح هذا المفتاح للنشر في Google Play؛ يلزم مفتاح إصدار خاص هناك.

## قيود الإصدار التجريبي

لا توجد مصاحف أو تلاوات أو حسابات أو قاعدة بيانات أو مفاتيح API. هذه النسخة لا تتجاوز إعدادات النظام ولا تدّعي نجاح التفعيل دون صلاحية Android.
